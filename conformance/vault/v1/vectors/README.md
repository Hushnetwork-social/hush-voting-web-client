# Vault v1 Vectors (Phase 3+)

Deterministic public-synthetic vectors land here in later phases:

- positive envelope/record/key-package vectors;
- Unicode / password / KDF / HKDF / AES-GCM vectors;
- native-wrapper logical vectors;
- migration and generation fixtures;
- tamper/negative vectors with expected typed codes;
- extension compatibility vectors.

All values are declared public test credentials (see `../metadata.json`
`publicTestCredentials`) and are confined to this allowlisted path.
